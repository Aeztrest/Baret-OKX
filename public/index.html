01 · How it works

Three steps, one verdict

Baret never signs, holds keys, or submits anything on-chain. It only answers one question: is this transaction safe to sign?

01

Decode & check

Baret decodes the calldata against known ERC-20/721/1155 and proxy signatures, then checks live on-chain state — contract code, balances — via RPC.

  • 4-byte selector match
  • On-chain state check
  • No signing, no custody
02

x402 pays per call

Every call is metered with the x402 protocol: no payment header → HTTP 402 with the price; a valid USDC payment → the check runs and settles.

  • Pay per call in USDC
  • No accounts, no API keys
  • Standard x402 v1
$0.01 per check_transaction call
03

Agent gets a verdict

The agent gets safe/unsafe, a risk level, and human-readable reasons — decode it once in code, decide every time.

  • Machine-readable JSON
  • Plain-language reasons
  • MCP tool + REST

05 · Connect your agent

Two ways in, same answer

Call it like a normal API, or point an MCP-aware agent at it directly. Either way you get back the same plain verdict: safe, or not.

Which one do I want? Calling from your own code? Use the REST API — it's one HTTP request. Is your agent already built on a framework that speaks MCP? Point it at the MCP tool directly, no extra glue code.

07 · Security & privacy

What runs where

You're trusting Baret with the moment before a signature. Here's exactly what it does with it.

Runs on a stateless server

Baret receives the pending transaction, decodes and checks it, and returns a verdict. It never sees a private key.

Never signs, never submits

Baret only returns an opinion. The calling agent decides what to do with the transaction.

No custody, no accounts

No wallet, no login, no API key to leak. Access and payment are both per-call, via x402.

A preflight, not a guarantee

Findings reflect decoded calldata and on-chain state at call time — a strong signal, not a certainty.

08 · FAQ

Fair questions

What happens if I don't send a payment?

You get an HTTP 402 with the exact price and payment details. No payment, no check.

Does it work on any EVM chain?

Yes — pass network as an eip155:<chainId> id and, optionally, your own RPC URL.

Is it free to try?

The REST and MCP endpoints are pay-per-call. Discovery routes (tools/list, /health) are always free, and the demo on this page runs unmetered.

What does "unsafe" actually mean?

At least one high or critical severity finding — an unlimited approval, a proxy upgrade, an ownership transfer, insufficient balance, or a blocklist hit.

Does Baret hold my funds or keys?

No. Baret never signs, never submits, and never takes custody of anything. It only analyzes and returns an opinion.

Can the detectors be extended?

Yes — each is a small, independent function. Add a new one without touching the others.
